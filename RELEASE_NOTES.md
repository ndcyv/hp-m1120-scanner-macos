# Release notes — v1.3.2 source release

- Native macOS AppKit interface for scanning using the patched SANE backend
- Single-page output as PDF, PNG, JPEG
- Multiple manually scanned sheets combined into one PDF
- Optional offline searchable PDF (macOS Vision framework)
- Installer generates an original application icon locally
- Supports grayscale or colour at 150–600 DPI

Only one Apple Silicon iMac with macOS 27 has been tested. Other platforms and versions are unverified. No notarized binary is distributed; build from source locally.
